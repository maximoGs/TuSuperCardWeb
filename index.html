✦ ¿Cómo publicar tu versión en GitHub Pages gratis?

  1. Haz un Fork o clon de este repositorio en tu cuenta de GitHub.
  2. Personaliza tus tarjetas e información profesional en este panel.
  3. Haz clic en "Descargar cards-data.js" y reemplaza el archivo en la carpeta js/cards-data.js.
  4. Haz git commit y git push a tu repositorio.
  5. En GitHub, activa Settings → Pages → Deploy from branch (main). Tu Hub profesional estará en línea.
